# Zapret GUI — Fixes (2026-01-01)

## 1. CSRF-защита для расширения браузера
- Добавлен `check_csrf()` в `api_extension_add` и `api_extension_remove` (`zapret_gui.py`).
- Расширение (`extension/popup.js`) теперь отправляет заголовок `X-CSRF-Token` с мета-тегом страницы.

## 2. Безопасность сервера (отсутствие авторизации + критические операции)
- Сервер работает на `127.0.0.1:8080` без авторизации и имеет прямой доступ к системным операциям (`sc create`, `net start`, `taskkill`, реестр, загрузка zip с GitHub).
- Добавлена базовая валидация `.bat`-файлов (`validate_bat_content`) перед выполнением или установкой службы.
- Установлены ограничения на содержимое `.bat` (запрещены `powershell`, `wmic`, `netsh`, `sc delete`, `reg add`, `del `, `format`, `diskpart`).

## 3. Валидация `.bat`-файлов
- Функция `validate_bat_content` проверяет `.bat`-файл перед запуском (`api_start`, `api_service_install`) и при построении аргументов службы.
- Это предотвращает выполнение произвольных команд через подмену `.bat`-файлов в папке zapret.
